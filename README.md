## “不限流量”和 fair-share 端口是怎么回事

JustHost 全部套餐都写 Unmetered port，后面跟一句 fair-share，再注明等效流量：300Mbps 端口约等于每月 93TB，500Mbps 约 155TB，750Mbps 约 232TB，10Mbps 的 Promo 约 4TB。

这里的“不限流量”指的是不按 GB 计费、不设月度流量上限，但端口是共享的，忙时按公平原则分配带宽。你拿到的 300Mbps 是端口上限，不是 24 小时都能跑满的保证带宽。那串 93TB、155TB 是按满速跑满整月算出来的理论值，实际用不到，反过来说也意味着正常用途基本不会触发流量限制。

真正需要留意的带宽档位只在小配置上：Promo 的 10Mbps 端口，满速下载约 1.25MB/s，更新系统、拉 Docker 镜像会明显慢；New Star 的 100Mbps 够日常；300Mbps 以上基本感觉不到差别。选套餐时，端口这一列在低端档才是决策因素。

## 便宜 VPS 的线路问题：JustHost 没有承诺国内优化

这是“性价比 VPS”类文章最容易被含糊过去的一段。

国内访问速度取决于回程走什么线路，跟 CPU、内存、价格没有关系。常见的几档：

- **163 骨干网**：骨干节点以 202.97 开头，用的人最多、优化程度最低，出国方向容易拥堵、丢包偏高，2021 年扩容后体验有改善。
- **CN2 GT**：CN2 的中端产品，去程和回程都可能出现 202.97 节点，晚高峰会堵。
- **CN2 GIA**：CN2 里最高端的一档，路由基本全走 59.43 节点，最稳、最少拥堵，价格也最高。
- **CMI**：走 223.120 网段、AS 号 AS58453 时才是中国移动 CMI，只写 CMI 的往往是移动单线，电信联通接上去体验差。
- **AS9929**：原网通骨干网，现在是联通第二大网，对联通用户友好。

同样 1 核 2GB 的机器，价格能差好几倍，差的就是这段路由。JustHost 的套餐价格页上没有标注 CN2 GIA、CN2 GT 这类中国优化线路，所以不能默认它走的是优质回程。如果你的主要用途是国内访问（远程桌面、代理、面向国内用户的站点），下单前先用最低档月付试一个月，实际 ping 和 traceroute 一遍，比看任何测评都准。Promo 那档 $1.99 就是干这个用的。

如果你的用途是海外建站、跑国际业务、做备份节点、跑自动化脚本，线路影响很小，这时候低价才是真优势。

## 常见问题

**1GB 内存够用吗？**
跑一个 WordPress + MySQL，1GB 会紧，得配 swap，访问量一上来就卡。跑静态站、Nginx 反代、单个 Docker 容器、爬虫脚本、监控 agent，1GB 够。判断标准很简单：你的应用常驻内存超过 600MB，就上 2GB。

**能建站吗？**
能，KVM 架构，root 权限完整，装什么面板、什么环境都自己决定。但官网没标托管服务，环境要自己配。建站的话建议从 Arcturus（2GB）起，硬盘 30GB 放几个站的图片和数据库够用。

**续费会涨价吗？**
官网价格页展示的是常规月付价和 12 个月付款折后价，没有单独一套续费价。年付到期时按当期页面价格续，官方调价就跟着变。想稳成本，就在到期前一个月看一眼当期价格再决定续不续。

**能退款吗？**
公开评测提到 JustHost 有 15 天退款保障。条款细节（是否限首次购买、是否扣支付手续费、Promo 这类特价档是否适用）在下单页和服务条款里确认，别只看宣传页。

**Promo $1.99 那档值得买吗？**
作为验证机值得，作为长期主力不值得。512MB 内存 + 10Mbps 端口 + 只能月付，三个限制叠在一起决定了它就是个试用品。拿它测一周延迟和 IO，满意了再上年付的 Sirius 或 Arcturus。

**年付会不会跑路？**
任何低价 VPS 都有这个风险，无法通过文章消除。可控的做法是：先月付试一个月，确认机器和网络符合预期再转年付；重要数据保持本地和异地各一份；不把全部业务压在一台年付机器上。年付省下的 20%，本质上是拿“提前付款”换的折扣，别把它当成免费。
